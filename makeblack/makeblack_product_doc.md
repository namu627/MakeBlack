# MakeBlack 제품 설명서

> 할 일을 완료할 때마다 팔레트에 물감이 떨어진다. 색이 쌓이고 섞일수록 검정에 가까워진다. 모든 할 일을 완료하면 — BLACK.

---

## 1. 이 앱은 무엇인가

MakeBlack은 **todolist + 팔레트 아트**가 결합된 앱이다.

기존 할일 앱은 체크하고 끝이다. MakeBlack은 할 일을 완료할 때마다 **고유한 색상이 캔버스에 물감처럼 퍼진다**. 색이 하나씩 추가될수록 서로 혼합되어 점점 어두워지고, 모든 할 일을 완료하면 팔레트가 완전한 **검정(BLACK)**이 된다.

이 경험이 핵심이다. 체크리스트의 딱딱한 완료감이 아니라, **오늘 하루가 팔레트 위에 기록되는 시각적 보상**이다.

---

## 2. 왜 만들었나

할일 앱은 이미 넘쳐난다. 노션, 투두이스트, 애플 리마인더… 모두 훌륭하지만 **매일 쓰고 싶은 이유**가 약하다. 체크해도 뿌듯함이 오래 가지 않는다.

MakeBlack은 이 문제를 **시각적 달성감**으로 해결한다. 오늘 팔레트가 얼마나 채워졌는지 한눈에 보인다. 어제보다 더 채우고 싶어진다. BLACK을 달성한 날은 캘린더에 특별하게 표시된다.

거기에 **팀 기능**을 더했다. 팀원과 함께 팔레트를 채우면 각자의 색이 섞여 하나의 팔레트가 만들어진다. 팀플 과제, 스터디, 회사 프로젝트 — 함께 BLACK을 향해 가는 경험이다.

---

## 3. 핵심 개념

### BLACK이란
하루에 등록된 모든 할 일을 완료하면 달성되는 상태다. 팔레트가 검정으로 수렴하고, 특별한 애니메이션이 재생되며, 캘린더에 그날이 BLACK으로 기록된다.

### 팔레트란
매일 새로 시작하는 빈 캔버스다. 할 일을 완료할 때마다 고유한 색상의 물감이 팔레트 위에 퍼진다. 색은 서로 겹치고 섞이며, 완료된 할 일이 많을수록 팔레트는 더 풍부하고 어두워진다.

### 색상 혼합
실제 물감의 감산혼합 원리를 따른다. 파란 물감과 빨간 물감을 섞으면 어두워지는 것처럼, 팔레트의 색도 많이 섞일수록 검정에 가까워진다. 단순한 평균이 아니라 CMY 색상 공간에서 혼합하므로 자연스러운 물감 느낌이 난다.

## 4. 앱 구조 (화면별)

앱은 하단 네비게이션 4개 탭으로 구성된다.

```
홈  |  검색  |  팀  |  마이페이지
```

---

## 5. 홈 화면

앱의 메인 화면. 오늘 할 일과 팔레트를 관리한다.

### 5-1. 상단 영역

**날짜 네비게이션**
- 중앙에 현재 날짜가 표시된다 (오늘이면 "오늘", 다른 날이면 "3월 14일")
- 양옆 ◀ ▶ 버튼으로 전날/다음날 이동
- "캘린더" 버튼으로 달력 시트를 열어 날짜 직접 선택 가능
- 미래 날짜도 선택 가능 — 미리 할 일을 등록하거나 완료 처리할 수 있다

**팔레트 캔버스**
- 정사각형 캔버스에 물감 잉크 효과로 drop이 그려진다
- 크기는 설정에서 소/중/대로 조절 가능
- 할 일 완료 시 새 drop이 애니메이션으로 퍼짐

**프로그레스바**
- 팔레트 아래에 가로 바 형태
- 완료된 할 일의 색상으로 그라데이션 표시
- 왼쪽에 완료된 할 일의 색 도트 (최대 10개, 초과 시 "+N")
- 오른쪽에 "완료수 / 전체수"

### 5-2. 할일 목록

**카테고리 시스템**
- 할 일은 카테고리 단위로 묶인다
- "카테고리" 버튼 → 카테고리 관리 모달
- 각 카테고리는 색상이 있고, 할 일 추가/완료 시 해당 색상 계열로 팔레트에 표현됨
- 카테고리 순서는 드래그로 변경 가능

**할일 추가**
- 카테고리 옆 + 버튼 → 입력창 열림
- Enter 키 또는 ↵ 버튼으로 추가
- Escape로 취소
- 추가된 할 일은 팔레트 색상과 연결된 고유 색상을 가짐

**할일 완료**
- 왼쪽 원형 체크박스 클릭
- 완료 시 체크박스가 해당 색으로 채워지고, 팔레트에 물감이 퍼짐
- 완료 해제 시 팔레트에서 해당 drop 제거
- 완료된 항목은 흐려지며 취소선 표시

**할일 편집**
- 할일 텍스트 더블클릭 → 인라인 편집 모드
- Enter 또는 저장 버튼으로 확정, Escape로 취소
- 루틴으로 생성된 할일은 편집 불가

**할일 삭제**
- 오른쪽 ✕ 버튼
- 완료된 할일 삭제 시 팔레트에서도 해당 drop 제거

### 5-3. 카테고리 관리

"카테고리" 버튼을 누르면 모달이 열린다.

**카테고리 탭**
- 색상 팔레트에서 색 선택 후 이름 입력 → 추가
- 기존 카테고리 목록에서 ⠿ 핸들을 드래그해 순서 변경
- ✕ 버튼으로 삭제 (확인 다이얼로그 표시, 해당 카테고리의 루틴도 함께 삭제)

**루틴 탭**
루틴은 매일 자동으로 나타나는 고정 할 일이다.

루틴 설정 항목:
- **카테고리**: 어느 카테고리에 속할지
- **루틴 이름**: 할 일 텍스트
- **반복 타입**: 요일 반복 또는 날짜 반복
  - 요일 반복: 월/화/수/목/금/토/일 중 선택 (복수 가능)
  - 날짜 반복: 매월 몇 일인지 선택 (예: 10일, 25일)
- **기간**: 시작일과 종료일 설정 (종료일 없으면 무한 반복)

루틴으로 생성된 할일은 "루틴" 뱃지가 표시되고, 편집/삭제 불가.

### 5-4. 캘린더 시트

"캘린더" 버튼으로 위에서 내려오는 시트.

- 월 단위로 표시, ‹ › 버튼으로 달 이동
- 각 날짜 셀에 팔레트 미니 원 표시 (팔레트 히스토리가 있는 날)
- **날짜 숫자 색상으로 상태 구분**:
  - 밝은 흰색 = 미완료 할 일 있음
  - 어두운 회색 = 할 일 없음
  - 흐린 회색 = 모두 완료
  - 빨간색/파란색 = 일요일/토요일
- 미완료 날짜: 흰 테두리 표시
- BLACK 달성 날짜: 팔레트 원이 선명하고 흰 링 표시
- 날짜 클릭 → 해당 날짜로 이동 + 시트 닫힘

### 5-5. BLACK 달성 시퀀스

모든 할 일을 완료하면 자동으로 시작된다.

1. 검정 오버레이가 화면을 덮음 (흰 원이 펄스)
2. "BLACK" 텍스트와 "모든 색이 하나가 됐어요" 표시
3. 오버레이가 사라지며 캘린더가 열림
4. 흰 구체가 화면 중앙에서 캘린더의 오늘 날짜 셀로 날아감
5. 셀에 착지하며 스탬프 + 파문 애니메이션
6. 캘린더가 닫힘

오버레이 클릭으로 즉시 스킵 가능. 설정에서 애니메이션 끄기 가능.

---

## 6. 검색 화면

친구를 찾고 팔로우하는 화면.

### 6-1. 검색

- 이름 또는 @아이디로 검색
- 실시간 결과 표시
- X 버튼으로 검색어 초기화

### 6-2. 유저 카드

검색 결과와 친구 목록에서 유저 카드를 볼 수 있다.

카드에 표시되는 정보:
- 아바타 (핸들 기반 고유 그라데이션 색상)
- 이름, @아이디, 소개
- BLACK 달성 횟수, 팔로워 수

**팔로우/언팔로우**
- "팔로우" 클릭 → 즉시 팔로우
- "팔로잉" 클릭 → 언팔로우 확인 버튼 표시 후 확정

### 6-3. 친구 목록 탭

- 팔로우한 사람들 목록
- 탭 옆에 친구 수 뱃지 표시
- 여기서도 바로 언팔로우 가능

## 7. 팀 화면

친구와 함께 프로젝트를 관리하는 화면. 팀 할 일을 공유하고 팀 팔레트를 함께 채운다.

### 7-1. 팀 목록

- 내가 속한 팀들의 카드 목록
- 각 카드: 팀 이름, 설명, 멤버 수, 멤버 색 도트, 진행률 바, 미니 팔레트
- 팀 검색 (이름으로 필터)
- "+ 팀 만들기" 버튼

### 7-2. 팀 만들기

- 팀 이름 (필수), 설명 (선택)
- 만들면 내가 팀장(첫번째 멤버)이 됨
- 생성 후 팀 상세 화면으로 이동

### 7-3. 팀 상세 화면

팀 할 일과 팔레트를 관리하는 메인 화면.

**헤더 영역**
- 팀 이름, 설명
- 멤버 아바타 행 — 각자 고유 색상 원으로 표시
- "+ 초대" 버튼 → 초대 모달
- "···" 메뉴 버튼

**멤버 고유 색상 시스템**
팀에 가입한 순서대로 색이 배정된다:
1번째 멤버 → 블루 계열
2번째 멤버 → 레드 계열
3번째 멤버 → 그린 계열
4번째 멤버 → 옐로우 계열
5번째 멤버 → 퍼플 계열
(이후 민트, 오렌지, 핑크 순으로 계속)

이 색상이 체크박스, 팔레트 drop, 멤버 뱃지에 일관되게 사용된다. 팔레트를 보면 누가 얼마나 기여했는지 한눈에 파악된다.

**날짜 네비게이션**
- 개인 홈과 동일하게 날짜 이동 가능
- "캘린더" 버튼으로 팀 캘린더 시트 열기
- 날짜별로 독립적인 팀 할 일과 팀 팔레트 히스토리

**팀 팔레트**
- 160x160px 캔버스
- 멤버 각자가 완료한 할 일의 색상으로 팔레트가 채워짐
- 여러 멤버의 색이 섞이며 BLACK을 향해 수렴

**팀 카테고리와 할일**
- 팀 안에서 카테고리 생성 가능 (내 색상으로 자동 배정)
- 모든 멤버가 카테고리에 할 일 추가 가능
- 할 일 오른쪽에 작성자 미니 아바타 뱃지 표시
- **삭제 권한**: 본인이 작성한 할 일 또는 팀장만 삭제 가능

**팀 BLACK 달성**
- 선택된 날짜의 팀 할 일을 모두 완료하면 발동
- "팀이 해냈어요" 메시지와 함께 애니메이션
- 설정에서 팀 BLACK 애니메이션 개별 on/off 가능

### 7-4. 멤버 초대 모달

- 아이디 직접 입력 후 초대
- 또는 내가 팔로우한 친구 목록에서 선택 (아직 팀원이 아닌 사람만 표시)
- 현재 멤버 목록 확인 (팀장 뱃지 표시)

### 7-5. ··· 메뉴

**팀장인 경우**:
- 팀 정보 수정 (이름, 설명)
- 팀 삭제 (확인 다이얼로그)

**일반 멤버인 경우**:
- 팀 나가기 (확인 다이얼로그)
- 마지막 멤버가 나가면 팀 자동 삭제

## 8. 마이페이지

내 프로필과 통계를 보는 화면.

### 8-1. 프로필

- 아바타 (그라데이션 원)
- 이름, @아이디, 소개
- 팔로워 수, 팔로잉 수 (클릭 시 검색 탭의 친구 목록으로 이동), BLACK 달성 수

### 8-2. 이번 달 통계

4개의 수치 카드:
- **완료한 할 일**: 이번 달 완료한 총 할 일 수
- **활동한 날**: 할 일이 있었던 날 수
- **BLACK 달성**: 이번 달 BLACK을 달성한 날 수
- **연속 달성**: 연속으로 BLACK을 달성한 일수 (전달까지 이어짐)

이번 달 평균 완료율 바 차트.

요일별 평균 완료율 막대 그래프 (일요일/토요일은 빨강/파랑).

### 8-3. 월간 히트맵

이달 달력 형태의 진행 현황:
- 활동 없음: 어두운 배경
- 진행 중: 파란 계열 (진행률에 따라 밝기 변화)
- BLACK 달성: 흰색 배경 + 흰 테두리

### 8-4. 설정 (⚙ 버튼)

오른쪽 상단 톱니바퀴 버튼을 누르면 아래서 올라오는 설정 시트.

## 9. 설정

### 계정 관리
- 이름, 핸들(@아이디), 이메일, 소개 변경 가능
- 각 항목 옆 "변경" 버튼 클릭 → 인라인 편집
- 계정 삭제 버튼 (추후 서버 연동)

### 공개 범위
내 할 일과 팔레트를 누가 볼 수 있는지 설정:
- **전체 공개**: 모든 사람
- **팔로워만**: 나를 팔로우한 사람
- **비공개**: 나만
(현재는 UI만 구현, 서버 연동 후 실제 동작)

### 알림 설정
- 매일 리마인더 on/off
- 리마인더 시간 선택 (시간 picker)
(현재는 UI만 구현, 실제 발송은 Expo Notifications 연동 후)

### 앱 설정
- **테마**: 🌙 다크 / ☀️ 라이트 (즉시 적용)
- **캘린더 시작 요일**: 일요일 / 월요일 (즉시 적용)
- **24시간 표기**: 오후 2시 → 14:00 (추후 시간 표시 시 적용)
- **언어**: 한국어 / English (UI만 구현)

### 팔레트 설정
- **BLACK 달성 애니메이션** (홈): on/off
- **팀 BLACK 애니메이션**: on/off
- **팔레트 크기**: 소 / 중 / 대 (즉시 적용)

### 앱 잠금 (PIN)
- on/off 토글
- PIN 설정: 4자리 숫자 키패드로 입력 → 확인 입력
